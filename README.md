# 📌 Project Overview

GroviQ AI is a modern full-stack grocery intelligence platform engineered to simulate a production-grade AI SaaS dashboard experience.

# ⚙ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/sujalkrshaw/groviq-ai-dashboard.git
```

---

## 2️⃣ Navigate to Project

```bash
cd groviq-ai-dashboard
```

---

## 3️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 4️⃣ Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

## 5️⃣ Configure Environment Variables

Create `.env` file inside backend folder.

```env
MONGO_URI=your_mongodb_connection
PORT=5000
```

---

## 6️⃣ Run Backend

```bash
npm run server
```

---

## 7️⃣ Run Frontend

```bash
cd ../frontend
npm run dev
```
